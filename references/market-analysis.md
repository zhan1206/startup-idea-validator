# 市场规模分析方法论

本文档介绍 Startup Idea Validator 使用的市场规模分析方法。

## TAM/SAM/SOM 概念

### TAM (Total Addressable Market) - 总可寻址市场
- 理论最大市场规模
- 假设产品可以服务所有潜在用户
- 通常用总地址容量或年度总支出表示

### SAM (Serviceable Addressable Market) - 可服务市场
- 基于你的地理位置、分销渠道等可以实际服务的部分
- 通常是 TAM 的 10-30%

### SOM (Serviceable Obtainable Market) - 可获得市场
- 实际可以获取的市场份额
- 基于竞争格局、执行能力等
- 通常是 SAM 的 5-20%

## 估算方法

### Top-Down（自上而下）
```
TAM = 潜在用户数 x 平均年消费
    = 10亿人 x ¥100/年
    = ¥1000亿
```

### Bottom-Up（自下而上）
```
目标客群 = 100万中小企业
转化率 = 5%
客单价 = ¥10,000/年
SOM = 100万 x 5% x ¥10,000 = ¥50亿
```

## 注意事项

1. **数据时效性**：市场数据通常有 1-2 年的滞后
2. **地域差异**：中国和美国市场差异很大
3. **定义边界**：确保对市场边界的定义清晰一致
4. **增长假设**：增长率是否可持续？
5. **渗透率假设**：你的产品能占多少份额？

### 中国市场特点

- 市场规模约为全球的 15-20%
- 增长速度快于全球平均
- 竞争更加激烈
- 监管环境独特
- 支付习惯不同（移动支付主导）
