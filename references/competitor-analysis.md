# 竞品分析方法论

本文档介绍竞品分析的方法和框架。

## 竞品分类

### 1. 直接竞品 (Direct Competitors)
提供相同核心功能，满足相同用户需求
- 例子：美团外卖 vs 饿了么

### 2. 间接竞品 (Indirect Competitors)
提供不同方案满足相同需求
- 例子：外卖平台 vs 便利店速食

### 3. 潜在竞品 (Potential Competitors)
未来可能进入市场的玩家
- 例子：大型平台的内部孵化项目

### 4. 替代品 (Substitutes)
完全不同的解决方案
- 例子：在线视频 vs 线下电影院

## 竞品分析维度

### 产品维度
| 维度 | 内容 |
|------|------|
| 核心功能 | 主要解决什么问题 |
| 用户体验 | 易用性、界面设计 |
| 技术架构 | 性能、稳定性、可扩展性 |
| 定价策略 | 收费模式、价格区间 |
| 目标用户 | 用户画像、使用场景 |

### 市场维度
| 维度 | 内容 |
|------|------|
| 市场份额 | 市场规模、用户数量 |
| 增长趋势 | 用户增长、收入增长 |
| 获客渠道 | 主要获客方式 |
| 品牌认知 | 品牌知名度、口碑 |

### 商业模式维度
| 维度 | 内容 |
|------|------|
| 盈利模式 | 如何赚钱 |
| 单位经济 | LTV、CAC、回收期 |
| 毛利率 | 产品利润空间 |
| 资金状况 | 融资轮次、现金储备 |

## 差异化分析框架

### 1. 价值链分析
分析竞品在价值链各环节的优劣势：
- 采购/供应
- 生产/研发
- 营销/销售
- 配送/服务
- 售后/支持

### 2. 用户旅程分析
从用户视角看竞品体验：
1. 发现 → 如何被用户知道
2. 认知 → 如何理解产品价值
3. 转化 → 如何完成首次使用
4. 使用 → 核心体验如何
5. 留存 → 如何持续使用
6. 推荐 → 如何传播口碑

### 3. 竞争定位图
用二维矩阵定位竞品：

```
高价格                    低价格
  ↑                        ↑
  │  Quadrant 1           │  Quadrant 2
  │  (高端市场)           │  (性价比)
  │                       │
  │───────────────────────│
  │  Quadrant 4           │  Quadrant 3
  │  (小众市场)           │  (大众市场)
  └───────────────────────┴──→ 高质量
                            低质量
```

## 寻找差异化机会

### 1. 用户细分
- 聚焦特定人群（年龄、职业、规模）
- 聚焦特定场景（工作、生活）
- 聚焦特定地域（一线城市、南方市场）

### 2. 功能差异
- 核心功能更出色
- 解决竞品忽略的功能
- 简化复杂功能

### 3. 体验差异
- 更好的用户界面
- 更流畅的使用体验
- 更人性化的客服

### 4. 商业模式差异
- 不同的定价策略
- 不同的获客方式
- 不同的变现模式

## 竞品信息获取渠道

1. **官方渠道**
   - 公司官网、产品介绍
   - 新闻发布会、融资公告
   - 官方社交媒体

2. **第三方数据**
   - App Store / Google Play 排名和评论
   - SimilarWeb, App Annie 数据
   - 天眼查、企查查

3. **用户反馈**
   - 应用商店评论
   - 社交媒体讨论
   - 论坛和社区

4. **行业报告**
   - 艾瑞咨询
   - 36氪研究院
   - CB Insights
